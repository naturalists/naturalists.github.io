01. Wie ben ik?

Ik ben een eerstejaars student aan de MBO 4 opleiding tot Software Developer. In dit eerste jaar focus ik me sterk op de fundamentele bouwstenen van programmeren. Ik ben snel comfortabel geworden met core-concepten zoals variabelen, loops, functies en databases.

Mijn interesse ligt zowel bij server-side scripting met PHP als het bouwen van applicaties met NodeJS. Omdat mijn GitHub-repositories momenteel op privé staan i.v.m. schoolrichtlijnen, laat ik mijn projecten en code graag live zien tijdens een presentatie of op locatie via een demo.
